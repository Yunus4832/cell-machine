# 示例

[中文](README.md) | [English](README.en.md)

所有 `.cell` 文件都可以直接粘贴到 `web/index.html` 的源码区域运行。

| 文件                 | 说明                                                          |
| -------------------- | ------------------------------------------------------------- |
| `hello.cell`         | 输出 `Hello, Cell!` 后进入稳定自循环                          |
| `yes-forever.cell`   | 永久输出 `yes`                                                |
| `interactive.cell`   | 从字符端口读取，回答 `yes` 或 `no`                            |
| `running-light.cell` | 向数值端口产生往返位图                                        |
| `collatz.cell`       | 仅用基本指令实现 Collatz 不规则轨道                           |
| `dynamic.cell`       | 生成 `;10`、保存入口指针并通过 `@` 间接执行                   |
| `call-return.cell`   | 用 `P` 保存返回地址，用 `@` 调用和返回                        |
| `bracket-sugar.cell` | 演示无参数 `[]` 的相对回填、`()` 的绝对回填与 `:*` 可移植自旋 |

网页参考环境把端口零解释为字符流，其余端口显示为当前 `A+4` 位数值事件。

根目录中的 `.cell` 文件以 `A=8` 为基准，也可以在参数范围、程序容量和地址布局允许时重新编译到更大的规格。网页内置示例采用更细的适配策略：

- `A=4–6`：生成短小的计数、倒计时、端口和括号示例；
- `A=7、8、10、12`：使用完整示例集，并将数据区自动放在地址空间中点。

动态代码示例使用 `+*` 构造与目标 A 对应的紧凑机器字，因此不会把 `A=8` 的编码误用于更宽的机器。

[`4+4/`](4+4/) 保存适合 16 Cell 物理原型的独立微型程序；网页会将同类程序按当前 A 自动扩展 operand 和循环偏移。
