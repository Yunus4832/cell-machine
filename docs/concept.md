# 概念设计

[中文](concept.md) | [English](concept.en.md)

## 定义

计算细胞（Cell）是一种状态完全局部、规模严格有限、代码与数据同构、行为由极少指令直接描述，并以端口作为外部组合边界的持续计算单元。

它具备一个独立计算主体所需的最小闭环：

```text
状态：有限统一内存
执行：程序指针 PP
操作：数据指针 DP
判断：条件控制流
交互：输入输出端口
持续：地址环绕且没有终止状态
适应：代码可读写并可作为数据生成
组合：端口可连接环境和其他 Cell
```

## 与 Brainfuck 的关系

Brainfuck 是这个项目最重要的思想来源。它用程序指针、数据指针、纸带和八条命令表达一般计算，证明复杂性可以来自少量规则的长期重复。

Cell Machine 保留：

- PP 与 DP；
- 当前单元作为隐式计算焦点；
- `><+-[],.` 的符号和基本直觉；
- 少量规则产生复杂行为；
- 指令即语言的透明关系。

Cell Machine 改变：

- 无限纸带变成 `2^A` 个 `A+4` 位统一内存字；
- 每条指令可以携带 A 位参数，一次覆盖目标机器的完整地址空间；
- 无参数 `[]`、`()` 在编译时对称配对回填，不在运行时扫描；显式参数形式始终是独立条件跳转；
- 代码和数据由同一内存承载；
- I/O 参数成为逻辑端口号；
- 新增绝对控制流、指针反射和通过数据间接改变 PP 的能力；
- 单个无限机器的复杂性转为有限 Cell 的复制和组合。

它不是 Brainfuck 兼容实现，而是把 Brainfuck 的极简哲学从抽象图灵机推进到有限物理计算单元。

## 核心原则

### 有限

Cell 不假装拥有无限资源。有限性使每个立即数、地址和状态都能被完整描述。

### 持续

Cell 没有 HALT、程序末尾或崩溃状态。PP 从最大 A 位地址自然回到零。程序可以进入固定点或周期，但这不等于架构停机；环境可以停止提供执行周期，但那不属于 Cell 语义。

### 全定义

每个 `A+4` 位机器字都可以安全执行。16种4位 opcode 全部有定义，全零字 `>0` 无副作用；地址和算术环绕；未连接端口由平台提供确定行为。

### 局部

数据操作围绕 DP 指向的当前字，控制操作围绕 PP。核心不暴露通用寄存器、栈、异常或隐式全局状态。

### 统一

一条 `A+4` 位机器字既能作为数据，也能被 PP 当成指令取出。`P`、`D` 把 PP、DP 变成普通数据，`@` 再把 DP 相对位置中保存的数据解释为程序入口。这形成“指针 → 数据 → 控制流”的反射闭环。

### 开放

I/O 端口把核心与平台解耦。核心只定义端口编号与数据传输，端口设备及其状态属于平台。同一程序可以连接网页字符流、GPIO、DAC、传感器、邻居 Cell 或游戏对象。

### 可组合

单个 Cell 保持小而完整；更复杂的能力通过复制 Cell 和改变连接拓扑产生。

## 不是缩小的传统 CPU

传统 CPU 主要优化单体程序性能、软件兼容性和大地址空间。Cell 优化的是：

```text
完整状态可见
复制成本低
实现容易验证
程序与机器关系透明
局部通信自然
代码可变异和迁移
虚拟实现与物理实现语义一致
```

当前核心指令是：

```text
> < + - =
[ ] ( ) : ;
P D @
, .
```

总数恰好是16，即 `2^4`。4位 opcode 固定这16条行为；源码符号由编译器映射为0到F。扩展机器规模通过增加地址/参数位宽 A 完成，而不是继续扩大核心指令集。

因此当前核心刻意没有：

- 通用寄存器堆；
- 硬件调用栈；
- 缓存与虚拟内存；
- 异常与特权级；
- 停机和断点指令；
- 标签、函数和类型系统。

## 复杂性的归属

硬件复杂性会被复制到每一个 Cell，并在每个周期付费；编译器复杂性通常只实现一次。因此自动括号回填、注释和错误检查适合交给编译器。

但复杂性必须有收益。当前边界是：

> 编译器可以帮助人准确表达已有机器语义，但不应悄悄创造新的语言抽象。

自动括号正符合这一边界：无参数 `[]` 回填相对地址，无参数 `()` 回填绝对地址；显式参数时四种括号都是独立机器指令。语法糖没有增加运行时状态，只把容易出错的地址计算交给工具。

`*` 也遵循同一原则：它只在编译时展开为目标 A 位宽的全一 operand，不增加 opcode 或运行时状态。典型写法 `:*` 因而能在不同规格上表达同一个固定点自循环。

## 有限确定性与“混沌”

孤立 Cell 的状态有限，因此确定性程序最终必然进入固定点或周期。这不妨碍它产生很长、难以直观预测的轨道。接入外部端口、随机源或其他 Cell 后，整体状态空间和交互复杂度会迅速增加。

`examples/collatz.cell` 展示有限机器中的不规则轨道；`examples/dynamic.cell` 展示数据生成程序并改变控制流。

## 组合愿景

Cell 可以成为：

- 可编程元胞自动机中的一个格子；
- 数字生物的基因组兼大脑；
- 游戏对象内部的脚本虚拟机；
- FPGA 中替代中等复杂状态机的控制核；
- 信号、灯光和音乐网络中的一个节点；
- 大规模局部消息传递阵列中的处理元素。

复杂性不来自某个 Cell 变得巨大，而来自：

```text
少量指令 × 大量时间 × 大量 Cell × 连接拓扑
```
